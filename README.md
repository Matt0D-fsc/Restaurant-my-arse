# The Courtyard at Park Heights — Luxury Experience

A luxury restaurant, art gallery, and culinary sanctuary website for **The Courtyard at Park Heights** (Dhanmondi, Dhaka).

Reimagined with the visual architecture, micro-interactions, GSAP ScrollTrigger choreography, Lenis smooth scrolling, and dynamic fullscreen menu inspired by *latabledejoakim.fr*.

## ✨ Features
* **Brand Preloader**: Staged luxury loading curtain with progress indicator and animated monogram.
* **Lenis Smooth Scroll**: Momentum scrolling physics.
* **GSAP 3 & ScrollTrigger**: Staggered text animations, SplitText character hover effects, and parallax reveals.
* **Dynamic Fullscreen Menu**: Real-time background image crossfading & backdrop color transitions on hover.
* **Swiper 11 Carousel**: Infinite loop signature dish showcase with pause-on-hover luxury card overlays.
* **Interactive Table Concierge**: Complete booking engine with party size, date/time pickers, and toast feedback.
* **Multi-Page Architecture**:
  * `index.html` — Main Landing Experience
  * `menu.html` — Categorized Culinary Catalog & Prices
  * `about.html` — Architecture, Skylight & Adda Philosophy
  * `contact.html` — Concierge & Private Event Inquiries

## 🚀 Running Locally
To launch a local static development server:

```bash
cd courtyard-experience
python -m http.server 3000
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
